# TimeTraveler

Project page for **TimeTraveler: Temporal Strategy Planning with Time Dictionary for Streaming Video Understanding** (NeurIPS 2026).

Live page: https://geppa.github.io/TimeTraveler/

Minkuk Kim (Kyung Hee University), Junho Kim (University of Illinois Urbana-Champaign), Seong Tae Kim (Kyung Hee University)

## Editing

- `index.html`: the page. The demo cases live in the `CASES` array near the bottom.
- `static/css/style.css`: theme. Kyung Hee Red `#A40F16`, Illini Orange `#FF5F05`, Illini Blue `#13294B`.
- `static/images/`: figures exported from the paper; demo frames are under `static/images/cases/`.
- `static/pdf/`: paper PDF.
